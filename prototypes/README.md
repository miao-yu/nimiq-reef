# Prototypes

Not wired into the app. Kept because throwing away working design work is
worse than a little clutter, and deleting a directory is one command.

- `character.mjs` — reef creatures as composable parts, the way a Nimiq
  identicon is: a seed picks a crest, eyes, mouth, pattern and fin from fixed
  sets, plus two colours. Written 26 Aug to answer whether a procedural
  creature can look collectible rather than anatomical. Render a sheet with
  the scripts in `.render/` (see git history of this commit for those).
